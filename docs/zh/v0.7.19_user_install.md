# v0.7.19 装机用户升级指南

> 适用于: 已装 pandaone-guard < 0.7.19 的用户
> date: 2026-10-17
> 预计时间: 2 分钟

## 1. 卸载旧版 (避 L5 TAMPERED 双装状态)

```bash
pip uninstall pandaone-guard -y
```

为什么要先卸载? 0.7.14 / 0.7.18 等老版本跟 0.7.19 同时存在 site-packages 会触发 L5 fingerprint 报警 (TAMPERED), 看着像被篡改实际是双装.

## 2. 装 0.7.19

```bash
pip install pandaone-guard==0.7.19
```

装完会自动装 14 个依赖 (psutil, openpyxl, lxml, pillow, python-docx, PyYAML, reportlab 等).

## 3. 验证版本

```bash
pandaone --version
```

期望输出: `pandaone v0.7.19`

## 4. 验证 7 层 doctor

```bash
pandaone doctor
```

期望结果: L1-L6 全 ok, L7 FAIL 预期 (装机用户没 `.github/workflows/audit.yml`).

```
L1_file_lock            : ok (python-only)
```

## 5. C 修复真生效 (新功能验证)

### C1: 导出 yaml/json/dot 时 metadata.version 不再是 0.1.0

```bash
pandaone export --format yaml
pandaone export --format json
pandaone export --format dot
```

期望: 任何导出文件里, metadata.version = 0.7.19 (不再死锁 0.1.0).

### C2: status 命令 PID 探活真查 (不死锁 running)

```bash
# 1. 开 watchdog (后台)
pandaone watch --daemon &

# 2. 查 status
pandaone status
```

期望: 看到 PID + alive + watchdog process cmdline. 老版本在进程被 kill 后还报 running (假阳性), 0.7.19 修好.
