# v0.7.20 装机用户升级指南

> 适用于: 已装 pandaone-guard < 0.7.20 的用户 (含 0.7.19 / 0.7.18 / 0.7.14 等)
> date: 2026-10-17
> 预计时间: 1 分钟
> 重要: P0-2 改了 fingerprint 算法, **升级必跑 update-fingerprint**, 少了 CLI 全部不可用

---

## 🚀 方式 1: 一键脚本升级 (推荐, 0.7.20 新增)

```powershell
# PowerShell (管理员模式 可选, 不是必须)
irm https://raw.githubusercontent.com/hellob1889/Pandaone-AI-Agent/v0.7.20/scripts/install-update.ps1 | iex
```

脚本自动做: 卸老版 → 下载 0.7.20 wheel → 装 → 跑 `--update-fingerprint` → 跑 `doctor` 7 层验。

---

## 🐍 方式 2: pip 升级 (最常用)

### 步骤 1: 卸载旧版 (避 L5 TAMPERED 双装)

```bash
pip uninstall pandaone-guard -y
```

> 为什么要先卸载? 0.7.18 / 0.7.19 等老版本跟 0.7.20 同时存在 site-packages 会触发 L5 fingerprint 报警 (TAMPERED), 看着像被篡改实际是双装.

### 步骤 2: 装 0.7.20

```bash
# 从 PyPI (推荐, 装机 99% 用户走这条)
pip install pandaone-guard==0.7.20

# 或从 GitHub Release 直接装 wheel (无网/内网环境)
pip install https://github.com/hellob1889/Pandaone-AI-Agent/releases/download/v0.7.20/pandaone_guard-0.7.20-py3-none-any.whl
```

### 步骤 3: 【必跑】重置指纹

```bash
pandaone --update-fingerprint 0000
```

> **少了这步, 跑任何命令会得到 `[ERROR] pandaone 指纹不匹配！可能被篡改。`**
> 原因: P0-2 修复把 fingerprint 算法从单文件
